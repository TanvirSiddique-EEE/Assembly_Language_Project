# Assembly_Language_Project

Student Data Table Management System (8086 Assembly – EMU8086)

This project was developed as part of our EEE 4606 (Control Systems Lab) final assessment. It is a simple yet powerful Student Data Table Management System written entirely in 8086 Assembly Language and tested on the EMU8086 emulator. The main goal was to design a program that can store and manage student records in a structured table format while exploring the challenges of low-level programming.

The system allows users to define their own table structure by choosing the number of columns and whether each column should be numeric or string-based. Once the structure is set, the user can input multiple rows of student data such as name, age, height, weight, or hometown. The program then neatly displays the data in a tabular format and offers sorting functionality: numeric columns are sorted in descending order, while string columns are sorted in dictionary (ASCII) order. This makes the table both flexible and interactive, despite being built on such a low-level language.
